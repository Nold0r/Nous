# Nous

Компаньон для Honkai: Star Rail. Tauri 2 (Rust) + React + TypeScript + Vite.

```sh
npm install
npm run tauri dev     # приложение с горячей перезагрузкой
npm run tauri build   # установщик
npm run assets        # иконки и шрифт игры из StarRailRes
```

Вся документация — хранилище Obsidian в [`../docs`](../docs/Nous.md):

- архитектура оболочки, регистрация экранов и разделов меню;
- дизайн-система: токены, компоненты, шаблоны экранов, чек-лист;
- пошаговое добавление нового экрана;
- Rust-команды, источники данных игры.

Живая витрина компонентов — экран «Дизайн-система» в меню (только в `tauri dev`).
