# Источники данных

Официального API у HoYoverse нет. Ниже — источники, на которые опираются будущие системы Nous, от самого безопасного к рискованному.

| Источник | Что даёт | Риск для аккаунта | Статус в Nous |
|---|---|---|---|
| **Датамайн** (TurnBasedGameData, StarRailRes, Hakushin) | Справочники: персонажи, предметы, уровни, координаты объектов на картах | нет | иконки и шрифт используются; данные уровней проверены в spike |
| **Профиль по UID** (Enka.Network, Mihomo) | Витрина профиля: до 8 персонажей со снаряжением | нет | — |
| **HoYoLAB API** (по cookie) | Энергия в реальном времени, ежедневки, все персонажи, эндгейм | нет | — |
| **История прыжков** (authkey из кэша игры) | Крутки за 6 месяцев, формат UIGF | нет | — |
| **OCR-сканер** | Инвентарь с экрана | низкий | — |
| **Пассивный перехват трафика** (Reliquary) | Весь инвентарь, состояние карт и сундуков, события в реальном времени | низкий, формально нарушает ToS | прототип `spike/hsr-sniff` работает |
| Чтение памяти, инъекции | — | **бан** | не используем никогда |

## Перехват трафика

- Библиотека [Reliquary](https://github.com/IceDynamix/reliquary) (Rust, MIT) разбирает и расшифровывает пакеты. Её версия привязана к версии игры (игра 4.6 ↔ reliquary 24).
- Захват идёт через PktMon (встроен в Windows), нужны права администратора. Захват нужно запустить **до входа в аккаунт**, ключ сессии ловится при логине.
- При VPN (WireGuard) PktMon отдаёт пакеты без Ethernet-заголовка, и их нужно оборачивать. Это уже учтено в spike.
