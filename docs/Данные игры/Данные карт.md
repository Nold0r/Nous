# Данные карт

Объекты локаций для [[Модуль карты|карты]] (сундуки, якоря, размещение текстуры карты) извлекаются из датамайна один раз и лежат в приложении. Они нужны, чтобы связать карту HoYoLAB с этажом игры и сопоставить открытые в игре сундуки с точками HoYoLAB: `app/src/data/maps/`, около 1,1 МБ.

## Состав

- `index.json`: `floorId → { planeId, name, chests, anchors }`.
- `floors/<floorId>.json`:

| Поле | Что |
|---|---|
| `name` | Русское название плана (+ «этаж N» у многоэтажных) |
| `bounds` | `[minX, minZ, maxX, maxZ]` в метрах |
| `chests` | `{ id, type, x, y, z, group, config, layer }`. `id` — MazeChest ID (тот же, что в пакетах игры), `type`: `normal` / `challenge` / `puzzle` |
| `anchors` | Пространственные якоря (объекты в состоянии `CheckPoint*`) |
| `mapInfo` | Размещение игровой текстуры карты (центр, размер, масштаб, размер текстуры, слои) из `Config/LevelOutput/Map/MapInfo_*.json`; по нему привязываются картинки HoYoLAB. `null`, если файла нет |

Покрытие: **237 локаций, 1762 из 2101 сундуков** игры. Остальные — в событийном или удалённом контенте, групп которого нет в датамайне.

## Пересобрать (после обновления игры)

1. Частичный клон датамайна ([TurnBasedGameData](https://gitlab.com/Dimbreath/turnbasedgamedata)):
   ```sh
   git clone --filter=blob:none --no-checkout --depth 1 https://gitlab.com/Dimbreath/turnbasedgamedata.git tbgd
   cd tbgd && git sparse-checkout init --no-cone
   # в .git/info/sparse-checkout:
   #   /ExcelOutput/
   #   /TextMap/TextMapRU_*.json
   #   /TextMap/TextMapMainRU.json
   #   /Config/LevelOutput/RuntimeFloor/
   #   /Config/LevelOutput/SharedRuntimeGroup/
   #   /Config/LevelOutput/RuntimeGroup/
   #   /Config/LevelOutput/Map/
   #   /Config/LevelOutput_Baked/Floor/
   git checkout main
   ```
   ~30 тысяч файлов групп. Файлы по одному не качайте, GitLab ограничивает частоту запросов.
2. Извлечение (~2 минуты):
   ```sh
   cd app
   python scripts/extract-maps.py <путь к tbgd>
   ```
