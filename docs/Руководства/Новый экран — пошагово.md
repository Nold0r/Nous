# Новый экран — пошагово

Пример: экран «Прыжки» (история круток) в новом разделе меню.

## 0. Опишите экран

Скопируйте [[Шаблон — спецификация экрана]] в `docs/Экраны/Прыжки.md` и заполните: зачем экран, какие данные, какая раскладка из [[Шаблоны экранов]], какие состояния.

## 1. Раздел меню (если нужен новый)

`app/src/features/categories.ts`:

```ts
{ id: 'warps', title: 'Прыжки', order: 30 },
```

Подробнее: [[Категории меню]].

## 2. Иконка

Подберите иконку в `icon/sign/` StarRailRes, например `DrawcardIcon`. Добавьте её в `app/scripts/assets.json` → `groups.sign.icons`:

```json
"warps": "DrawcardIcon"
```

Затем `npm run assets`. Подробнее: [[Иконки]].

## 3. Папка фичи

`app/src/features/warps/index.ts`:

```ts
import { defineModule } from '../types'
import { WarpsPage } from './WarpsPage'

export default defineModule({
  requires: ['hsr'],
  id: 'warps',
  title: 'История прыжков',
  screens: [{ id: 'warps', title: 'История прыжков', icon: 'warps',
    category: 'warps', component: WarpsPage }],
})
```

## 4. Экран

`app/src/features/warps/WarpsPage.tsx`, собранный из [[Компоненты|компонентов]]:

```tsx
import { Button, EmptyState, Page, Panel, ProgressBar } from '../../ui'

export function WarpsPage() {
  const warps = [] // данные из api.ts (шаг 5)

  return (
    <Page title="История прыжков" subtitle="Крутки и гарант" actions={<Button variant="primary">Импорт</Button>}>
      {warps.length === 0 ? (
        <EmptyState icon="warps" title="История пуста">
          Нажмите «Импорт», чтобы загрузить историю прыжков из игры.
        </EmptyState>
      ) : (
        <Panel title="Гарант">
          <ProgressBar label="До 5★" value={42} max={90} tone="gold" />
        </Panel>
      )}
    </Page>
  )
}
```

Готово: пункт появится в меню, экран откроется по `/#/warps`.

## 5. Бэкенд (если нужен)

Команда в Rust + `api.ts` в папке фичи, см. [[Rust и команды Tauri]].

## 6. Проверка

- `npm run tauri dev`: пункт в нужном разделе, иконка игровая, экран открывается.
- Пройдите [[Шаблоны экранов#Чек-лист нового экрана|чек-лист]].
- `npm run build` без ошибок (TypeScript проверит категорию и типы).

- [[Регистрация экранов]]
- [[Дизайн-система]]
