# Обновление игры

После выхода новой версии Star Rail всё, что нужно Nous, обновляет одна команда из `app/`:

```powershell
npm run game-update
```

Пока она не выполнена, захват не видит игру: каждый пакет новой версии отбрасывается, а в лог печатается номер неизвестной версии (например, `2766937619`).

## Что делает

| Шаг | Что | Откуда |
|---|---|---|
| `reliquary` | Переводит `vendor/reliquary` на upstream `main`: ключ расшифровки и протоколы новой версии | [reliquary](https://github.com/IceDynamix/reliquary) |
| `tables` | `npm run game-data`, `assets`, `spine-centers`: названия, значения, иконки, кадрирование артов | StarRailRes, HSR Optimizer |
| `datamine` | Частичный клон датамайна, обновлённый до последнего коммита | [TurnBasedGameData](https://gitlab.com/Dimbreath/turnbasedgamedata) |
| `textures` | Текстуры миникарты из файлов игры (AnimeStudio, только чтение) | установленная игра |
| `maps` | `map-textures` и `map-markers`; печатает новые и пропавшие локации | датамайн и текстуры |
| `check` | `cargo test --workspace`, `npm run test:modules`, `npm run test:data` | |

Рабочие файлы (датамайн, AnimeStudio, карта ресурсов, текстуры, несколько ГБ) лежат в `C:\nous-data`, вне репозитория. Карта ресурсов и текстуры хранятся по версии игры (`assetmap/4.7.0`, `textures/4.7.0`), поэтому повторный запуск на той же версии их не пересобирает.

Папку игры скрипт ищет сам: у запущенной игры, затем в обычных местах установки HoYoPlay и Steam.

## Параметры

```powershell
npm run game-update -- --only reliquary,check       # только эти шаги
npm run game-update -- --skip tables
npm run game-update -- --game "E:\SteamLibrary\steamapps\common\Star Rail Games"
npm run game-update -- --work D:\nous-data           # или NOUS_DATA_DIR
```

## Когда что-то не вышло

- **upstream reliquary ещё не обновлён.** Ключ новой версии появляется в нём обычно в течение дня-двух после выхода. Повторите `--only reliquary,check` позже.
- **датамайн ещё старый.** Последний коммит печатается в шаге `datamine`, в названии стоит версия (`OSPRODWin4.7.0_…`). Новых локаций не будет, пока датамайн не обновится.
- **`check` упал.** Чаще всего это переименованное поле в протоколах новой версии. Ошибки компиляции указывают на `crates/nous-hsr`.
- **Первая сборка reliquary** после обновления занимает 5–9 минут.

## После

1. Просмотрите `git status`: изменятся указатель submodule, `app/modules/map/maps.json`, `app/public/maps/`, таблицы в `app/src/assets/data/`.
2. Запустите программу, войдите в игру (ключ приходит только при входе) и откройте новую локацию.
3. Напишите патчноуты в `CHANGELOG.md`, раздел Unreleased.

Значки меток скрипт не трогает. Если игра их поменяла, см. [[Модуль карты#Сборка карт]], шаг 4.
