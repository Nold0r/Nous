# Вход в игру скриптом

Dev-скрипт `app/scripts/dev/hsr-session.ps1` входит в игру и выходит на экран входа, эмулируя клики. Нужен, чтобы сниффер увидел свежий вход (запись входа для [[Данные аккаунта#Проверки без входа в игру|тестов данных]]) без ручных нажатий. В приложение не входит.

```
npm run game:login     # запустить игру при необходимости и дойти до мира
npm run game:logout    # Esc → кнопка питания → «Подтвердить»: экран входа
npm run game:relogin   # выход, затем вход
```

> [!warning] Только из терминала администратора
> Игра работает с правами администратора, и Windows не пропускает к ней ввод от обычного процесса. Скрипт сам проверяет это и останавливается.

> [!info] Безопасность
> - Ввод идёт, только когда окно игры на переднем плане (иначе скрипт останавливается).
> - Если мышь или клавиатура использовались меньше 5 с назад, скрипт не стартует: значит, за компьютером человек. `-Force` отключает проверку.
> - Скрипт лишь нажимает то же, что нажал бы игрок; в игру ничего не внедряется. Решение пользоваться им — за вами.

## Этапы (игра 4.6, русский интерфейс)

Координаты — доли клиентской области окна, поэтому от разрешения и масштаба Windows не зависят. Сняты по скриншотам 02.11.2026 (окно 2560×1440, масштаб 125 %).

**Вход**

| Экран | Действие | Точка | Ждать |
|---|---|---|---|
| Запуск | `StarRail.exe` из реестра HoYoPlay, ждём окно | — | ~25 с до загрузки титульного экрана |
| Титульный: «HONKAI: STAR RAIL», сервер, справа «Объявления / Настройки / Выйти / Закрыть» | клик по свободному месту | (0,50; 0,55) | ~20 с: вход в аккаунт и загрузка ресурсов |
| «ВПЕРЁД»: полоса внизу, справа добавляется «Обновление» | клик «ВПЕРЁД» | (0,50; 0,937) | ~30 с до появления в мире |
| В мире | — | — | — |

**Выход на экран входа**

| Экран | Действие | Точка | Ждать |
|---|---|---|---|
| В мире | Esc: меню-телефон | — | 2,5 с |
| Меню-телефон | кнопка ⏻ внизу правой полосы | (0,973; 0,905) | 2,5 с |
| «Вы хотите вернуться на страницу входа?» | «Подтвердить» | (0,608; 0,621) | ~15 с |
| Титульный экран, «Добро пожаловать, …» | аккаунт входит сам, можно снова `login` | — | — |

## Ограничения

- Этапы определяются по времени, не по картинке. На медленном ПК: `... hsr-session.ps1 login -Slow 1.5`.
- Всплывающие окна при входе (объявления, ежедневная награда) не закрываются: в проверках 02.11 их не было. Если появятся, добавить этап.
- Если игра попросит логин и пароль (сессия истекла), скрипт не поможет: войдите вручную один раз.
- После обновления интерфейса игры точки надо перемерить по скриншотам.
