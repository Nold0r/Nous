# Игровые ресурсы

Иконки и шрифт берутся из [StarRailRes](https://github.com/Mar-7th/StarRailRes) скриптом `app/scripts/fetch-assets.mjs`. Список того, что качать, — `app/scripts/assets.json`.

```json
{
  "source": "https://raw.githubusercontent.com/Mar-7th/StarRailRes/master/",
  "groups": {
    "items":  { "path": "icon/item/{id}.png",   "content": 112, "icons": { "credits": 2 } },
    "sign":   { "path": "icon/sign/{id}.png",   "content": 104, "icons": { "map": "MapIcon" } },
    "avatar": { "path": "icon/avatar/{id}.png", "content": 128, "icons": { "8002": 8002 } }
  },
  "fonts": { "path": "font/{id}.ttf", "fonts": { "hsr-ui": "RPG_CN" } }
}
```

- `content` — размер картинки внутри квадрата 128 px. Чем меньше, тем больше поля. Одинаковый для всей группы, отсюда единый вид.
- Результат: `app/src/assets/icons/<группа>/<имя>.png` и `app/src/assets/fonts/<имя>.woff2`.
- Скрипт можно запускать повторно, файлы перезаписываются.

## Новая группа иконок

Например, иконки путей (`icon/path/`): добавьте группу в `assets.json`, затем в `src/lib/icons.ts` ещё один `import.meta.glob` по аналогии с остальными. Параметры glob пишутся прямо в вызове: Vite разбирает их статически.

## Полезные папки StarRailRes

| Папка | Что там |
|---|---|
| `icon/sign` | Иконки меню и интерфейса (вкладки) |
| `icon/item` | Предметы, валюты, материалы |
| `icon/avatar` | Аватары игрока и портреты персонажей |
| `icon/character` | Иконки персонажей |
| `icon/light_cone`, `icon/relic` | Конусы, реликвии |
| `icon/path`, `icon/element` | Пути и стихии |
| `index_new/ru/*.json` | Справочники с русскими названиями |
| `font/` | Шрифты игры |
