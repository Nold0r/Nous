# Ветки и релизы

Репозиторий: https://github.com/Nold0r/Nous

## Ветки

| Ветка | Для чего |
|---|---|
| `main` | Только готовый код. **Каждый push сюда собирает и публикует релиз**, и установленные копии Nous обновляются |
| `tab/overview` | Вкладка «Обзор» |
| `tab/characters` | Вкладка «Персонажи» |
| `tab/relics` | Вкладка «Реликвии» |
| `tab/map` | Вкладка «Карта» |
| `tab/settings` | Вкладка «Настройки» |
| `tab/design-system` | Dev-экран «Дизайн-система» |

Работа над вкладкой идёт в её ветке. Когда вкладка готова, ветка вливается в `main`:

```
git checkout main
git pull
git merge tab/map
git push            # запускает сборку релиза
```

Перед новой работой в ветке подтяните `main`, чтобы получить изменения оболочки: `git checkout tab/map && git merge main`.

> [!warning] Правки оболочки
> Общий код (`components/`, `ui/`, `lib/`, `src-tauri/`) лучше менять в `main` или в отдельной ветке и сразу вливать: если две вкладки поменяют его по-разному, будут конфликты.

## Автосборка

`.github/workflows/release.yml`, запускается на каждый push в `main` (или кнопкой «Run workflow» в Actions):

1. Версия = `major.minor` из `app/src-tauri/tauri.conf.json` + номер запуска workflow (например `0.1.7`). Чтобы начать новую серию, поменяйте `0.1.0` на `0.2.0`.
2. Сборка установщиков NSIS и MSI, подпись пакетов обновления.
3. Релиз `v<версия>` с установщиками и `latest.json`.

Сборка идёт ~10–15 минут.

## Патчноуты

**Каждый релиз выходит с патчноутом.** Перед слиянием в `main` опишите изменения для пользователя в разделе `## Unreleased` файла `CHANGELOG.md` в корне репозитория: по-русски, простыми словами, риски отдельно (⚠️).

- Сборка берёт этот раздел как описание релиза на GitHub (и оно попадает в `latest.json` обновления).
- После публикации сборка сама переименует раздел в `## vX.Y.Z — дата` и откроет новый пустой `## Unreleased` (коммит `github-actions[bot]`). Поэтому перед следующей работой сделайте `git pull` в `main`.
- Если раздел пуст, в релиз попадут заголовки слияний с прошлого релиза и предупреждение в логе сборки — так делать не надо.

## Автообновление

Nous при запуске (только релизная сборка, не `tauri dev`) читает
`https://github.com/Nold0r/Nous/releases/latest/download/latest.json`. Если версия новее, внизу меню появляется «Доступна версия … — Обновить»: установщик скачивается, ставится в тихом режиме и перезапускает программу.

> [!danger] Ключ подписи
> Обновления подписаны ключом `~/.tauri/nous-updater.key` (секрет `TAURI_SIGNING_PRIVATE_KEY` в GitHub). Публичная половина — в `tauri.conf.json` (`plugins.updater.pubkey`). **Сохраните копию ключа.** Если он потеряется, установленные копии перестанут принимать обновления, и всем придётся переустановить Nous вручную.
