# Nous

**Nous** — компаньон для Honkai: Star Rail в духе AlecaFrame для Warframe. Это приложение-оболочка: каркас (окно, боковое меню, профиль игрока, фон) плюс набор независимых **встроенных модулей** (с экранами или фоновой работой). Каждая фича подключается к своей системе: снифферу трафика, датамайну, HoYoLAB и т. д.

> [!info] Стек
> Tauri 2 (Rust) + React 19 + TypeScript + Vite. Код лежит в `app/`, эта документация в `docs/` (хранилище Obsidian).
