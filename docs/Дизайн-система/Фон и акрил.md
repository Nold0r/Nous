# Фон и акрил

## Фон: космос

`app/src/components/background/SpaceBackground.tsx` + `space.css`. Повторяет атмосферу экрана персонажа в HSR, но без платформы. Слои от дальнего к ближнему:

1. **Туманность.** Радиальные градиенты тёплых тонов плюс облачная текстура (SVG-шум).
2. **Звёзды** на canvas. Каждая — заранее отрисованный размытый спрайт с гауссовым спадом, без жёстких краёв. Около 7% звёзд яркие и крупные. Звёзды медленно «дышат»: период 5–12 с, у каждой своя фаза, глубина 10–35%.
3. **Дымка** — тёплое свечение низко над «горизонтом».
4. **Туман** — два дрейфующих слоя у нижнего края.
5. **Виньетка.**

**Параллакс:** слои сдвигаются за курсором с разной глубиной (6–34 px), плавно, с инерцией. Значения — в `space.css` (`calc(var(--px) * …)`), инерция — коэффициент `0.04` в `SpaceBackground.tsx`.

> [!tip] Правило движения
> Фон не должен отвлекать: медленно, мягко, без мигания. Если меняете параметры, оставайтесь в этих рамках. При `prefers-reduced-motion` туман не анимируется.

## Акрил

Класс `.acrylic` (в `ui/base.css`): полупрозрачный тон `--acrylic` + `backdrop-filter: var(--acrylic-blur)` + зерно `--grain`. Его используют боковое меню, `Panel`, `EmptyState` и всплывающее окно профиля (`--acrylic-strong`).

- Не вкладывайте акрил в акрил: внутри акриловой панели используйте `Panel variant="plain"`.

### Ловушка с position: fixed

> [!warning]
> `backdrop-filter` делает элемент контейнером для всех `position: fixed` внутри него. Всплывающее окно внутри акрила будет позиционироваться относительно панели и обрежется ею. **Всплывающие окна рендерите через портал** в `document.body` (`createPortal`), как сделано в `ProfileCard`.
