# Шрифт

Интерфейс набран **шрифтом самой игры** — HYQiHei 65J (`RPG_CN.ttf` из StarRailRes). Этим шрифтом в HSR написаны меню, характеристики, названия.

- `npm run assets` скачивает шрифт (12 МБ, в нём есть китайский) и **урезает до латиницы, кириллицы и знаков** → `app/src/assets/fonts/hsr-ui.woff2` (~28 КБ).
- Подключается в `ui/tokens.css` как семейство `HSR`, токен `--font-ui`.
- Если нужен новый символ (стрелка, спецзнак), добавьте его диапазон в `charset` в `scripts/fetch-assets.mjs` и перезапустите `npm run assets`.

## Особенности

- **Одно начертание.** Жирного нет, и браузер не должен его подделывать (`font-weight: 100 900` указан специально). Иерархия строится размером ([[Токены#Типографика]]) и цветом (`--text` / `--text-muted` / `--text-dim`).
- **Кириллица узкая, цифры широкие** в стиле DIN. Так задумано в игре, это не обрезка.
- Цифры моноширинные (`tabular-nums`), значения в колонках не прыгают.

> [!note] Лицензия
> Шрифт, как и иконки, принадлежит HoYoverse и распространяется сообществом через StarRailRes.
