# Компоненты

Все компоненты импортируются из одного места:

```ts
import { Page, Panel, Button, StatRow } from '../../ui'
```

Вживую они показаны на экране **«Дизайн-система»** (dev-режим).

## Page

Рамка любого экрана: заголовок с золотистой линией, подзаголовок, кнопки справа, ниже содержимое с отступом `--space-6` между блоками.

```tsx
<Page title="Реликвии" subtitle="Инвентарь реликвий" actions={<Button variant="primary">Обновить</Button>}>
  …
</Page>
```

Каждый экран начинается с `Page`. Свой заголовок не рисуем.

## Panel

Контейнер блока. По умолчанию акриловый.

| Проп | Описание |
|---|---|
| `title` | Заголовок блока (рисуется через `SectionTitle`) |
| `aside` | Правая часть заголовка: счётчик, ссылка, кнопка `sm` |
| `variant` | `acrylic` (по умолчанию) или `plain` — для панели внутри панели |
| `compact` | Меньше отступы — для карточек в сетке |
| `onClick` | Делает всю панель кликабельной (курсор, подсветка) |

> [!warning] Акрил в акриле
> Не кладите акриловую панель в акриловую: размытие удвоится. Вложенные — `variant="plain"`.

## SectionTitle

Заголовок блока: золотой ◆, текст, затухающая линия, справа `aside`. Используйте для группировки контента без панели.

## Button

| `variant` | Когда |
|---|---|
| `primary` | Главное действие экрана, **одно на экран**. Белая таблетка |
| `secondary` | Обычные действия. Обводка, как «Подробнее» в игре. По умолчанию |
| `ghost` | Второстепенное: «Отмена», «Сбросить» |
| `danger` | Удаление: красный текст без обводки. В подвале окна ставится слева, отдельно от остальных кнопок |

`size`: `md` (36 px) или `sm` (28 px, для заголовков панелей и строк). `icon`: игровая иконка или lucide. Остальные пропсы как у `<button>`.

## Tabs

Сегментный переключатель «Характеристики | Умения». Для 2–4 вариантов отображения внутри экрана. Для разделов экрана с отдельным адресом используйте подстраницы, см. [[Регистрация экранов#Подстраницы внутри фичи]].

```tsx
const items = [{ id: 'stats', label: 'Характеристики' }, { id: 'skills', label: 'Умения' }] as const
const [tab, setTab] = useState<'stats' | 'skills'>('stats')
<Tabs items={items} value={tab} onChange={setTab} />
```

## StatRow и StatList

Строка характеристики, как на экране персонажа: иконка, название, значение справа, опционально `/max`. `StatList` складывает строки с правильным отступом.

```tsx
<StatList>
  <StatRow icon="stellar-jade" label="Звёздный нефрит" value="12 480" />
  <StatRow icon="trailblaze-power" label="Энергия освоения" value="184" max="300" />
</StatList>
```

`icon` — имя предметной иконки (строка) или любой элемент, например `<GameIcon icon="map" size={20} />`.

## Switch

Строка настройки «вкл/выкл»: название и пояснение слева, переключатель справа, кликабельна вся строка.

```tsx
<Switch checked={on} onChange={setOn} label="Запускаться вместе с игрой" hint="Пояснение" />
```

Пропсы: `checked`, `onChange(checked)`, `disabled`, `label`, `hint`. Используйте для настроек; для действий — [[#Button]].

## Badge

Маленькая метка в обводке. `tone`: `neutral`, `gold`, `success`, `warning`, `danger`, `info`. Для статусов («Открыт», «Ошибка»), тегов и счётчиков.

## Rarity

Звёзды редкости в игровых цветах: `<Rarity stars={5} />`.

## ProgressBar

Тонкая полоса прогресса с подписью и «значение/максимум». `tone`: `default` (белый), `gold`, `success`, `danger`.

## EmptyState

Экран или блок без данных: иконка, заголовок, пояснение, что сделать, и опционально кнопка.

```tsx
<EmptyState icon="map" title="Нет данных о сундуках" action={<Button size="sm">Как подключить</Button>}>
  Откройте карту в игре при запущенном Nous.
</EmptyState>
```

## Grid

Адаптивная сетка карточек: столько колонок шириной не меньше `min` px, сколько влезет. `<Grid min={260}>…</Grid>`.

## Иконки: GameIcon и ItemIcon

- `GameIcon` — монохромная иконка игрового меню, перекрашивается в цвет текста.
- `ItemIcon` — цветная иконка предмета.

Подробнее в [[Иконки]].

## Select

Выпадающий список одного значения в стиле таблетки (своё меню, не системное). Пропсы: `value`, `options: { value, label }[]`, `onChange`, `title` — о чём выбор (подсказка и чтение экранным диктором). Клавиатура: ↓/Enter открывает, ↑/↓ — по пунктам, Enter — выбрать, Esc — закрыть.

## FilterMenu и FilterTags

Фильтр с **белым и чёрным списком**. Каждый пункт можно включить (зелёный, «показать только») или исключить (красный, «скрыть»). Клик по строке переключает по кругу: выкл → включить → исключить → выкл; кнопки + и ⊘ справа задают режим сразу. В кнопке — счётчики `+N` / `−N`, длинные списки (10+) получают поиск.

```tsx
const [sets, setSets] = useState<FilterState>({})
<FilterMenu label="Набор" options={[{ value: '101', label: '…', icon: <img …/> }]} value={sets} onChange={setSets} />
<FilterTags groups={[{ label: 'Набор', tag: '', options, value: sets, onChange: setSets }]} onReset={() => setSets({})} />
```

`FilterState` — `{ [value]: 'include' | 'exclude' }`. Как сочетать режимы, решает экран; в инвентаре: одно значение на предмет (слот, набор) — «включённые ИЛИ», «исключённые — никогда»; несколько значений (доп. характеристики) — «есть все включённые и ни одного исключённого».

`FilterTags` показывает выбранное тегами `Tag` с крестиком и кнопкой «Сбросить всё»; `tag` — короткое имя группы для тегов (`''` — без имени).

## Tag

Залитый чип: `tone="include"` (зелёный, +), `exclude` (красный, ⊘), `neutral`. С `onRemove` — крестик.

## SearchInput

Поле поиска: лупа, текст не обрезается по краям, крестик очистки, Esc очищает. Растягивается в ряду (от 200 до 420 px).

## TextArea

Многострочное поле: `label`, `hint`, счётчик `n / maxLength`, `onSubmit` по Ctrl+Enter, курсор при фокусе — в конце текста.

## Фокус

Фокус с клавиатуры — мягкий золотой ореол `--focus-ring` (`:focus-visible` в `base.css`) вместо квадратной системной рамки. Фокус мышью не подсвечивается.

## StatIcon и StatLine

- `StatIcon` — белая иконка характеристики игры (`IconMaxHP`, `IconCriticalChance`…, папка `assets/icons/property`, `npm run assets`), берёт цвет текста. `title` — название для подсказки.
- `StatLine` — характеристика иконкой и значением. `rolls` — улучшения золотыми ◆; `main` — выделенная полоса основной характеристики; `showLabel` — показать название текстом (в карточках только иконка, название — во всплывающей подсказке).

## PortraitCard

Карточка персонажа для сетки: квадратная картинка (бюст) на фоне цвета редкости, полоса редкости снизу, `topLeft`/`topRight`/`bottom` поверх картинки (стихия, эйдолоны, уровень), заголовок и строка под ним. `dimmed` — приглушить (путь, не выбранный в игре). С `onClick` — кнопка.

## ItemCard

Карточка предмета (реликвия, конус): картинка на плитке цвета редкости, золотая/фиолетовая/синяя линия по верхнему краю, название, строка `meta`, значки в углу (`badges`), содержимое и `footer` под линией. С `onClick` — вся карточка кнопка, при наведении приподнимается.

## Modal

`size="lg"` — широкое окно для двух колонок (подробности предмета), `subtitle` — строка под заголовком.

## Страница персонажа: HeroArt, RankRow, RelicOrbit, SetEffects, SkillRow, StatChip

- `HeroArt` — рамка большого арта персонажа на фоне редкости: `art` (картинка или анимированный арт), `children` поверх снизу. Сама ничего не анимирует — движется только арт.
- `RankRow` — ряд ступеней «достигнута / нет» (эйдолоны E1–E6): картинка, подпись, описание в подсказке.
- `RelicOrbit` — шесть реликвий как на экране реликвий в игре: четыре на кольце (голова слева вверху, ноги справа вверху, руки слева внизу, тело справа внизу), две планарные внутри. Только картинка и уровень; `onSelect(slot)` открывает подробности. Порядок слотов: голова, руки, тело, ноги, сфера, канат; `null` — пусто.
- `SetEffects` — «Эффект набора» как в игре: название набора золотом, бонусы с галочкой, если надето достаточно; без `count` — просто список.
- `SkillRow` — умение: иконка, вид, название, уровень (+ бонус зелёным).
- `StatChip` — бонус характеристики таблеткой: иконка, название, «+28%».
- `Pager` — «‹ 3 / 6 ›» для листания короткого списка, ←/→ на клавиатуре; кладётся в `Modal actions`.
- `Badge solid` — залитая метка поверх картинок (E2, S5).
- `Modal actions` — место в шапке окна перед крестиком.

## Редкость: один вид для всех карточек

Карточки предметов и персонажей (`ItemCard`, `PortraitCard`, `ItemTile`, `HeroArt`, шапка окна реликвии) собраны из общих классов, своих рамок и полосок у них нет:

| Класс | Что делает |
|---|---|
| `ui-r5` / `ui-r4` / `ui-r3` | Задаёт `--rarity` — цвет редкости |
| `ui-edge-top` / `ui-edge-bottom` | Полоса редкости вдоль края (2 px сверху, 3 px снизу) с затуханием к бокам. Это `border-image`, поэтому толщина всегда в целых пикселях при любом масштабе экрана, а `clip-path` скругляет углы вместе с полосой. Отдельной тонкой рамки у таких карточек нет |
| `ui-rarity-tile` | Фон под картинкой: цвет редкости, гаснущий по диагонали |
| `ui-lift` | Наведение кликабельной карточки: приподнять на 2 px; фокус с клавиатуры — золотое кольцо |

Полоса: сверху у `ItemCard` и шапки окна реликвии, снизу у `PortraitCard`, `HeroArt` и `ItemTile`. Скругление — `--radius-lg`.

> [!warning] Не рисовать полосу слоем с `height`
> При масштабе 125% 2 px — это 2,5 пикселя экрана: слой округляется то в 2, то в 3 пикселя и сдвигается в зависимости от положения карточки. Толщина рамки округляется всегда одинаково.

## ItemTile

Плитка складываемого предмета (материалы): картинка на фоне редкости, количество, название, полоса снизу.

## ExternalLink

Текстовая ссылка на сайт золотом с подчёркиванием; открывается в браузере, а не внутри Nous.

## Как добавить компонент

1. Создайте `app/src/ui/<Имя>.tsx`. Классы с префиксом `ui-<имя>` (БЭМ: `ui-card__title`, `ui-card--active`).
2. Стили — в `ui/components.css`, только через [[Токены]].
3. Экспортируйте из `ui/index.ts`.
4. Покажите на витрине `features/design-system/DesignSystemPage.tsx`.
5. Опишите здесь: назначение, пропсы, когда использовать.

> [!note] Когда компонент, а когда нет
> Элемент нужен в двух и более фичах или задаёт визуальный паттерн → компонент `ui/`. Нужен одной фиче → `features/<id>/components/`, но собран из компонентов `ui/` и токенов.
