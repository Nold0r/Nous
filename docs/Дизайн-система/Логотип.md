# Логотип

Знак Nous: кремовый вихрь, золотое кольцо в центре и пронзающая его малиновая игла.

## Файлы (`app/src/assets/brand/`)

| Файл | Назначение |
|---|---|
| `nous-logo.png` | Исходник 1024×1024, прозрачный фон, три плоских цвета |
| `nous-logo.svg` | Вектор для интерфейса: шапка меню, витрина, favicon (`public/favicon.svg`) |
| `nous-app-icon-<стиль>.svg/.png` | Иконки приложения по платформам, см. ниже. PNG 1024×1024 с прозрачным фоном |

## Иконка приложения

У Windows и macOS разные правила оформления иконок, поэтому иконок три (`scripts/make-app-icon.py <стиль>`):

| Стиль | Платформа | Как выглядит | Куда идёт |
|---|---|---|---|
| `windows` | Windows 11 (Fluent) | Без подложки: сам знак на прозрачном фоне почти во весь холст, свет сверху слева, мягкая тень снизу, тёмный контур | `icon.ico` 40–256 px, PNG, плитки `Square*Logo` |
| `windows-small` | Windows, мелкие размеры | То же без тени, знак крупнее, контур толще, чтобы не терялся | `icon.ico` 16–32 px |
| `mac` | macOS | Тёмная скруглённая плитка, знак с тенью и бликами, в стиле иконки Obsidian | `icon.icns` |

- **Тёмный контур** у Windows-вариантов обязателен: без подложки кремовый знак растворяется на светлом меню «Пуск» и панели задач в светлой теме.
- `icon.ico` содержит 10 размеров (16, 20, 24, 32, 40, 48, 64, 96, 128, 256). Windows берёт из него иконки ярлыка, меню «Пуск», панели задач, окна и установщика.
- Внутри интерфейса используется знак **без плитки и контура** (`nous-logo.svg`).

## Цвета

| Цвет | HEX | Токен | Роль в интерфейсе |
|---|---|---|---|
| Кремовый | `#E9E4DA` | `--brand-cream` → `--select-bg` | Выбранная вкладка, primary-кнопка |
| Золото | `#D8B875` | `--brand-gold` → `--gold` | Акценты: ◆, пометки, прогресс исследования |
| Малиновый | `#B53E58` | `--brand-crimson` → `--crimson` | «Игла»: тонкий фирменный штрих |

Подробнее о токенах: [[Токены#Бренд]].

## Правила

- Логотип всегда на тёмном фоне, без подложки и обводки. Минимальный размер 24 px: на нём ещё читаются вихрь и игла.
- Не перекрашивать, не поворачивать, не растягивать.
- В шапке меню 38 px рядом со словом **NOUS** (капс, разрядка 6 px).
- Малиновый — штрих, а не заливка: линии толщиной 1–2 px, точки. Для ошибок есть `--danger`.

## Как пересобрать

```sh
# SVG из PNG: по одному проходу potrace на каждый цвет
pip install potracer numpy pillow
python scripts/trace-logo.py src/assets/brand/nous-logo.png src/assets/brand/nous-logo.svg
cp src/assets/brand/nous-logo.svg public/favicon.svg

# иконки приложения: три стиля из контуров логотипа
for st in mac windows windows-small; do
  python scripts/make-app-icon.py $st src/assets/brand/nous-logo.svg src/assets/brand/nous-app-icon-$st.svg
done
# отрендерить каждый SVG в nous-app-icon-<стиль>.png 1024x1024 с прозрачным фоном
# (например headless Chrome: --default-background-color=00000000), затем
# разложить по платформам: PNG/плитки и ico из windows, icns из mac
python scripts/pack-icons.py
```

Иконка окна и ярлыка обновится после перезапуска `npm run tauri dev` или новой сборки установщика.
