# Иконки

Все иконки оригинальные игровые, из [StarRailRes](https://github.com/Mar-7th/StarRailRes). Скрипт `npm run assets` скачивает их и **нормализует**: обрезает прозрачные поля и вписывает в квадрат 128×128 с одинаковым отступом для всей группы. Поэтому иконки одного типа визуально одного размера.

## Группы

| Группа | Откуда | Компонент | Вид |
|---|---|---|---|
| `sign` | `icon/sign/<Name>.png` | `<GameIcon icon="map" />` | Монохромные иконки игрового меню. Через CSS-маску красятся в цвет текста, поэтому меняют цвет при наведении и на активной вкладке |
| `items` | `icon/item/<id>.png` | `<ItemIcon name="credits" />` | Цветные иконки предметов и валют |
| `avatar` | `icon/avatar/<id>.png` | `avatarIcons[id]` | Круглые аватары игрока |

## Что уже есть

**sign:** `overview` (DataBankIcon), `map` (MapIcon), `characters` (AvatarIcon), `inventory` (InventoryIcon), `settings` (SettingsIcon).

**items:** `stellar-jade` (900001), `credits` (2), `trailblaze-power` (11), `reserved-trailblaze-power` (12).

**avatar:** `8001`, `8002` (Первопроходец).

## Добавить иконку

1. Найдите файл в StarRailRes. Для меню — папка `icon/sign/`; там 200+ иконок: `QuestIcon`, `ShopIcon`, `AchievementIcon`, `MailsIcon`… Для предмета нужен ID из `ExcelOutput/ItemConfig.json` датамайна или из `index_new/ru/items.json` StarRailRes.
2. Допишите в `app/scripts/assets.json` в нужную группу: `"короткое-имя": "ИмяФайла"` или `ID`.
3. `npm run assets`.
4. Используйте по короткому имени. Регистрировать нигде не нужно: `lib/icons.ts` подхватывает всё из папок.

## Правила

- Иконка вкладки меню — **только `sign`**. lucide-react допустим лишь для dev-экранов и временных заглушек.
- Внутри интерфейса `GameIcon` 16–22 px, в пустых состояниях 44 px.
- `ItemIcon` в строках 30 px, в плитках 36 px.
- Не перекрашивайте цветные `items`-иконки и не используйте `sign`-иконки как картинки.
