# Шаблоны экранов

Типовые раскладки, из которых собираются новые экраны. Выберите подходящую, прежде чем рисовать что-то своё.

## 1. Список-сетка

Для коллекций: персонажи, реликвии, световые конусы.

```
Page  title · subtitle                       [фильтры] [primary]
├─ Tabs (варианты отображения)        — опционально
└─ Grid min=220
   ├─ Panel compact onClick  (карточка)
   └─ …
```

- Карточка: иконка или портрет, название, `Rarity`, 1–2 `Badge`.
- Клик ведёт на подстраницу `/<id>/:itemId`.

## 2. Детали

Для одного объекта: персонаж, реликвия, локация.

```
Page  title (имя объекта) · subtitle      [secondary] [primary]
└─ Grid min=360
   ├─ Panel title="Характеристики" → StatList
   ├─ Panel title="…"
   └─ …
```

Похоже на экран персонажа в игре: слева визуальная часть, справа `StatList`.

## 3. Дашборд

Для «Обзора» и сводок.

```
Page title="Обзор"
├─ Grid min=260   (плитки-сводки: Panel compact + ProgressBar / StatRow)
└─ Panel title="…" (крупный блок, например список задач)
```

## 4. Карта или рабочая область

Для карты сундуков и подобного.

```
Page title · actions
└─ Panel (без title, растянута)  → своя визуализация
   + Panel compact поверх или сбоку для легенды и фильтров
```

## 5. Настройки

```
Page title="Настройки"
├─ Panel title="Группа 1" → строки «название — контрол»
└─ Panel title="Группа 2"
```

## Состояния — обязательны для каждого экрана

| Состояние | Как показать |
|---|---|
| Нет данных / аккаунт не привязан | `EmptyState` с объяснением, что сделать |
| Загрузка | Каркас из пустых `Panel` и `ProgressBar` без значений; без «прыгающих» спиннеров |
| Ошибка | `EmptyState` + `Badge tone="danger"` с текстом ошибки и кнопкой «Повторить» |
| Нормальное | Сам контент |

## Чек-лист нового экрана

- [ ] Начинается с `<Page>`, заголовок совпадает с названием в меню
- [ ] Использует только компоненты `ui/` и [[Токены]], нет своих цветов и размеров
- [ ] Не больше одной `primary`-кнопки
- [ ] Есть все состояния: пусто, загрузка, ошибка
- [ ] Нет выдуманных чисел: либо реальные данные, либо 0 / `EmptyState`
- [ ] Иконка в меню — игровая (`sign`), см. [[Иконки]]
- [ ] Не импортирует другие фичи
- [ ] Описан по [[Шаблон — спецификация экрана|шаблону спецификации]]
