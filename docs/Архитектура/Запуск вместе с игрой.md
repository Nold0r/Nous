# Запуск вместе с игрой

Сниффер ловит вход только если Nous уже работает в момент логина и с правами администратора (см. [[Сниффер]]). Поэтому Nous умеет жить рядом с игрой. Код: `app/src-tauri/src/launch.rs`, фронт: `lib/game.ts`.

## Что есть

| Что | Как работает |
|---|---|
| **Трей** | Закрытие окна прячет Nous в трей, сниффер продолжает работать. Клик по значку — открыть, меню — «Открыть Nous» / «Выход» |
| **Один экземпляр** | Повторный запуск (ярлык, меню «Пуск») не открывает вторую копию, а показывает окно первой (`tauri-plugin-single-instance`) |
| **Окно с игрой** | Раз в 2 с Nous проверяет процессы. Когда появляется `StarRail.exe`, окно Nous показывается само |
| **Кнопка «Играть»** | Под профилем в меню, видна только пока игра не запущена. Запускает игру через `Start-Process`. Из релизного Nous (он всегда администратор) игра стартует без второго окна UAC; если Nous без прав и игрок нажал «Нет» в окне UAC, кнопка просто возвращается, без ошибки |
| **Настройки → «Запускаться вместе с игрой»** | Создаёт задачу Планировщика `Nous`: при входе в Windows, с наивысшими правами, `nous.exe --background`. Nous стартует скрытым в трее, без окна UAC. При включении/выключении Windows один раз спрашивает разрешение |

## Где Nous берёт путь к игре

1. `game_path.txt` в папке данных приложения — путь, который Nous видел у запущенной игры (читается, только когда Nous запущен от администратора, как и игра).
2. Реестр HoYoPlay: `HKCU\Software\Cognosphere\HYP\<версия>\hkrpg_<регион>\GameInstallPath` (+ `StarRail.exe`), также ветка `miHoYo` для китайской версии.

Если пути нет, кнопка «Играть» неактивна с подсказкой запустить игру один раз.

## Команды и события

| Команда / событие | Что |
|---|---|
| `get_game_status`, событие `game-status` | `{ running, path }` |
| `launch_game` | Запустить игру |
| `get_autostart` / `set_autostart(enabled)` | Состояние / включить-выключить задачу автозапуска |

## Перезапуск от администратора

`restart_as_admin` ждёт ответа в окне UAC: «Нет» — Nous продолжает работать как был; «Да» — новая копия стартует с `--wait-pid <pid старой>` и ждёт, пока старая закроется, иначе защита от второго экземпляра закрыла бы новую. Общий помощник `shell_start` (launch.rs) отличает отказ в UAC (код Windows 1223) от настоящих ошибок и отдаёт их текстом в UTF-8.

## Ограничения

- Повторный запуск показывает работающую копию: в релизе обе копии с правами администратора, поэтому Windows пропускает сигнал между ними.
- При удалении Nous задача Планировщика остаётся. Выключите переключатель перед удалением или удалите задачу `Nous` в Планировщике.
