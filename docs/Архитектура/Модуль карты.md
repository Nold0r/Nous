# Модуль карты

> [!warning] Сейчас не реализовано
> Экран «Карта» — заглушка (`features/map/MapPage.tsx`). Всё ниже описывает **прежнюю реализацию**, удалённую 02.11.2026; её код лежит в истории git. Из неё сохранён только бэкенд мира — локация, позиция, сундуки, состояния объектов (`src-tauri/src/world.rs`, см. [[API данных игры]]). Заметка оставлена как справка для будущей карты.

Экран **«Карта»** (`features/map`, адрес `/#/map`) — копия [интерактивной карты HoYoLAB](https://act.hoyolab.com/sr/app/interactive-map) внутри Nous, поверх которой наложены данные из игры: позиция игрока и сундуки, открытые в игре.

## Что повторено из HoYoLAB

Страница HoYoLAB была разобрана по скриншотам и ответам API.

| HoYoLAB | Nous |
|---|---|
| Регион, список локаций, переключатель этажей | **Не повторено намеренно**: карта всегда на локации и этаже игрока |
| Группы категорий («Точки интереса», «Книги», «Противники», «Видимый сундук»…) с «глазом» и сворачиванием | Легенда **справа**, с иконками HoYoLAB и счётчиками «найдено/всего» на этой карте |
| Тайлы карты, точки — круглые значки с иконкой категории | То же; найденные полупрозрачные с зелёной галочкой, выбранная с золотой обводкой |
| Ползунок масштаба внизу по центру, колесо, перетаскивание | То же; двойной клик — вписать карту |
| Карточка точки: скриншот, описание, видео | То же + «Отметить найденным» |
| Комнаты (изометрические «3D»-карты) поверх карты с «« Закрыть» | То же: точка-вход в комнату открывает её поверх, «« Закрыть» возвращает |
| День / ночь у комнат Амфореуса | Переключатель ☀ / ☾ внизу слева в комнате |

Не повторено (не нужно или требует аккаунта HoYoLAB): журнал обновлений, маршруты, комментарии и правки точек, синхронизация отметок с аккаунтом. Отметки «найдено» хранятся локально.

## Данные из игры поверх

Работает, только когда на экране **карта этажа, на котором стоит игрок**:

- **Стрелка игрока.** Позиция и поворот из [[Сниффер|сниффера]], переведённые в пиксели картинки.
- **Связка всех меток с игрой** (`features/map/link.ts`). Каждая точка HoYoLAB связывается с объектом этажа из датамайна того же вида (сундук ↔ сундук, якорь ↔ якорь, остальное ↔ механизмы; противники не связываются — они возрождаются) один к одному, ближайшие пары первыми (до 15 px ≈ 4 м). Выполнено ли — по состоянию объекта из игры (`PropState`, приходит из [[Сниффер|сниффера]] при входе в сцену, при взаимодействии и с картой в игре):

  | Вид | Выполнено, когда |
  |---|---|
  | Сундук | открыт (id в списке открытых) или `ChestUsed` (13) |
  | Якорь | `CheckPointEnable` (8) |
  | Механизм / головоломка | `Open` (1), `TriggerEnable` (10) или `EventOpen` (19) |

  Сундуки-награды за головоломки появляются далеко от своей точки в датамайне, поэтому: открытые при работающем Nous связываются по **месту, где стоял игрок** при открытии (до 20 px), а оставшиеся точки «Сундук-головоломка» — с ближайшим свободным сундуком-головоломкой до ~30 м. В карточке точки: «Открыт / Активирован / Пройдено в игре» или «Не пройдено в игре».

- **Только локация игрока.** Выбора локации нет: показывается карта этажа, где стоит игрок; «Следить за игроком» включено по умолчанию.
- **Этаж выбирается сам.** У многоуровневой локации HoYoLAB даёт карту на каждый уровень («этаж 1», «этаж −1»). Слой карты — слой большинства наших объектов, совпавших с её точками. Слой игрока — голосование 5 ближайших к нему объектов этажа в 3D (уровни лежат на разной высоте; например, у Стиксии слой 1 на −102…−69 м, слой 2 на 15…71 м). `map_layer` из пакета движения во многих местах равен 0, поэтому он только запасной вариант.

## Как карта HoYoLAB связана с этажом игры

1. Кандидаты — карты HoYoLAB, у которых название локации или этажа совпадает с названием этажа из датамайна.
2. Картинка HoYoLAB — это **игровая текстура карты, увеличенная в k раз, плюс поля** (`padding`). k = 1 у небольших карт и ~1,18 у больших (Амфореус): `k = (size − 2·padding) / размер текстуры` из `MapInfo` датамайна, по обеим осям одинаковый (допуск 2 %).
3. Перевод координат точный: `px = padX + (x − (cx − w/2))·scale·k`, `py = padY + (cz + h/2 − z)·scale·k`.
4. Если подходят несколько картинок (слои одного этажа), берётся та, на которую ложится больше всего наших сундуков и якорей.

> [!note] История
> Первая версия подбирала привязку по пространственным якорям. На «Облачной переправе» якорей HoYoLAB всего 3 почти на одной линии, и сундуки съезжали на ~100 м. Через `MapInfo` расхождение 1–2 м. `MapInfo` есть у 86 этажей, на них 1752 из 1762 сундуков.

## Загрузка с HoYoLAB

Всё грузится в потоке, только для показанной карты:

| Запрос | Что | Кеш |
|---|---|---|
| `tree` | Дерево регионов, локаций, этажей, комнат | сутки |
| `info` + `point/list` | Тайлы, размер, `padding`, `origin`; точки | сутки |
| `label/tree` | Категории с русскими названиями и иконками | сутки |
| `point/info` | Карточка точки | сутки |

Тайлы и иконки грузятся браузером прямо с CDN HoYoLAB.

- **Прокси.** Webview не может обращаться к API HoYoLAB напрямую (CORS), поэтому запросы идут через команду Rust `hoyolab_map_api` (`src-tauri/src/hoyolab.rs`). Разрешены только эти пять эндпоинтов.
- **`app_version`.** API требует хеш сборки сайта HoYoLAB. Прокси знает текущий, а при ответе `-502` сам находит новый в JS-бандле страницы карты.
- Токен HoYoLAB не нужен: карта публичная.

## Устройство

| Файл | Что |
|---|---|
| `lib/hoyolab.ts` | Клиент API: каталог (регионы, локации, разделы, комнаты и их пары день/ночь), карты, категории, карточки точек, кеш; сопоставление с этажом игры (`findMapForFloor`, `gameTransform`) |
| `features/map/MapPage.tsx` | Экран: карта этажа игрока, определение слоя, комнаты, отметки, автоотметки, стрелка игрока |
| `features/map/MapLegend.tsx` | Легенда справа: категории, счётчики, переключатели |
| `features/map/MapView.tsx` | Карта: тайлы, точки, игрок, масштаб, слоты для переключателей |
| `features/map/PointCard.tsx` | Карточка точки |
| `features/map/map.css` | Стили, только токены |

Локально хранится (localStorage): скрытые категории `nous:map:hidden-labels`, ручные отметки `nous:map:found-points`, кеш HoYoLAB `hoyolab:v<N>:*`.
