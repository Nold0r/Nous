# Сниффер

Системный модуль, общий для всех экранов с данными из игры. Он пассивно читает трафик игры и восстанавливает из него данные аккаунта: профиль, реликвии, световые конусы, материалы, персонажей.

> [!info] Безопасность
> Сниффер только **читает копию** сетевого трафика через встроенный в Windows PktMon. В процесс игры он не лезет, пакеты не отправляет и не меняет. Риск и ограничения: [[Источники данных]].

## Файлы (`app/src-tauri/src/`)

| Файл | Что делает |
|---|---|
| `sniffer.rs` | Захват PktMon в фоне, расшифровка через reliquary, статус, события во фронт |
| `game.rs` | `GameState`: разбирает команды игры и держит текущий аккаунт |
| `inventory.rs` | Реликвии, конусы, материалы, персонажи из пакетов игры (по образцу reliquary-archiver) |
| `account.rs` | Хранение: один файл на аккаунт, см. [[Данные аккаунта]] |
| `profile.rs` | `PlayerProfile` и команда `get_profile` |

Reliquary подключён как git submodule `vendor/reliquary` (тег v24.0.0 = игра 4.6). После крупных патчей игры его нужно обновлять.

## Условия работы

1. **Права администратора.** Без них статус `needs_admin`; во всплывающем окне профиля есть кнопка «Перезапустить от администратора». Проще всего включить [[Запуск вместе с игрой]].
2. **Nous запущен до входа в игру.** Ключ сессии виден только при логине. Если игра уже запущена, выйдите на экран «Нажмите, чтобы начать» и войдите снова.
3. VPN (WireGuard и т. п.) поддерживается: пакеты без Ethernet-заголовка оборачиваются.

## Статусы (`sniffer-status`)

| `state` | Значит |
|---|---|
| `starting` | Запуск захвата |
| `needs_admin` | Нет прав администратора |
| `waiting_for_login` | Захват идёт, входа в игру ещё не было |
| `connected` | Вход пойман, данные расшифровываются |
| `error` | Захват остановился, текст в `message` |

## Команды игры, которые разбираются

| Команда | Что берём |
|---|---|
| `PlayerGetTokenScRsp` | UID → загружается файл этого аккаунта |
| `PlayerLoginScRsp.basic_info`, `PlayerSyncScNotify.basic_info` | Ник, уровень, энергия освоения, звёздный нефрит, кредиты |
| `StaminaInfoScNotify` | Энергия освоения и резервная энергия |
| `GetPlayerBoardDataScRsp` | `current_head_icon_id` — аватар |
| `GetBagScRsp` | Все реликвии, конусы, материалы |
| `GetAvatarDataScRsp` | Все персонажи |
| `PlayerSyncScNotify` | Изменения реликвий, конусов, материалов, персонажей |

## События во фронт

| Событие | Данные | Слушает |
|---|---|---|
| `profile-changed` | `PlayerProfile` | `useProfile()` в `lib/profile.ts` |
| `inventory-changed` | `reset` или изменения | `useInventory()` в `lib/inventory.ts` |
| `sniffer-status` | `SnifferStatus` | `useSnifferStatus()` в `lib/sniffer.ts` |

## Что сохраняется на диск

`%APPDATA%\com.nous.companion\accounts\` — файл на аккаунт, формат в [[Данные аккаунта]]. При запуске показываются данные последнего аккаунта («Данные с последнего входа»), пока игра не подключится.
