# Данные профиля

Профиль игрока показывается в верхней части бокового меню (плашка) и во всплывающей панели по клику.

## Поток данных

`src-tauri/src/profile.rs` → команда `get_profile` → `src/lib/profile.ts` (`useProfile()`) → `components/sidebar/ProfileCard.tsx`.

## Поля `PlayerProfile`

| Поле | Значение |
|---|---|
| `source` | `live` — данные из игры сейчас, `cached` — сохранены с прошлого входа, `none` — аккаунт не привязан |
| `nickname`, `uid`, `level`, `avatarId` | Ник, UID, уровень освоения, id аватара (файл `icon/avatar/<id>.png`) |
| `stellarJade`, `credits` | Звёздный нефрит, кредиты |
| `trailblazePower` / `trailblazePowerMax` | Энергия освоения |
| `reservedTrailblazePower` / `reservedTrailblazePowerMax` | Резервная энергия освоения |
| `updatedAt` | Unix-время последнего обновления |

## Правила отображения

- **Аккаунт не привязан** (`source: none`): все значения **0**, максимумы показываются (`0/300`, `0/2 400`, это константы игры в `profile.rs`). Под ником «Аккаунт не привязан», ник по умолчанию «Первопроходец», аватар по умолчанию Стелла (`8002`).
- **Данные из игры** (`source: live` или `cached`): под ником `UID …`, на аватаре плашка уровня. У `cached` в панели профиля пометка «Данные с последнего входа» с датой.
- **Никаких выдуманных цифр.** Заглушки-числа запрещены: либо реальные данные, либо нули.
- Кредиты от 100 000 сокращаются («18,65 млн»), полное значение показывается в подсказке.

## Откуда данные

Из трафика игры через [[Сниффер]]: ник, уровень, валюты и энергия из пакетов входа и синхронизации, резервная энергия из `StaminaInfoScNotify`, аватар из `GetPlayerBoardDataScRsp`. Изменения приходят событием `profile-changed`. Последний профиль сохраняется и при следующем запуске показывается как `cached`.

Аватар: `avatarId` — id картинки профиля в игре. `20XXXX` соответствует портрету персонажа `icon/avatar/XXXX.png`, остальные `IconHead_<id>.png` (StarRailRes, `avatarUrl()` в `lib/icons.ts`). Если картинку не удалось загрузить, показывается аватар по умолчанию.
