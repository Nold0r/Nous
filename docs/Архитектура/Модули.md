# Модули

Всё, кроме аккаунта и Настроек, — модули. Оболочка не называет ни одного модуля по имени: она находит их в `app/modules/` сама. Схема: [[Целевая архитектура]], холст структуры модуля — https://claude.ai/artifact/CZLUy5Pyub2z4m7pKEVPg6

## Из чего состоит модуль

```
app/modules/<id>/
  module.toml   как показать модуль в программе (обязательно)
  ui.tsx        экран вкладки или раздел плагина в Настройках (обязательно)
  module.rs     точка входа на Rust, если модулю нужна своя логика (по желанию)
  …             любые свои файлы рядом
```

### module.toml

```toml
id = "relics"            # = имя папки, kebab-case
title = "Реликвии"
kind = "tab"             # tab — вкладка в меню, plugin — раздел в Настройках
icon = "inventory"       # иконка из assets/icons/sign (или export icon из ui.tsx)
category = "inventory"   # раздел меню (только для tab), см. src/features/categories.ts
order = 1                # порядок внутри раздела
default = false          # открывается при запуске (не больше одного модуля)
badge = "beta"           # метка рядом с названием
dev_only = false         # только в dev-сборке
requires = ["hsr"]       # данные игры из Nous SDK: пока такой модуль включён, идёт захват

[rust]                   # только если есть module.rs
commands = ["get_status", "host::set_settings"]   # команды Tauri внутри модуля
```

Ошибка в манифесте видна сразу при запуске: «modules/<id>/module.toml: что не так».

### ui.tsx

```tsx
export default RelicsPage          // tab: экран; plugin: раздел в Настройках
export { Palette as icon } from 'lucide-react'   // необязательно: иконка-компонент
export function start(context) { … }             // необязательно: фоновая работа, пока модуль включён
export { OverlayApp as overlay }   // необязательно: страница окон поверх игры, адрес #/overlay/<id>/…
```

Модуль берёт строительные блоки оболочки через алиас `@app`: `@app/ui`, `@app/lib/inventory` и т. д.

### module.rs

Точка входа на Rust. Собирается вместе с приложением (`build.rs` подключает её как `crate::<id>`), обязана иметь:

```rust
pub fn setup(app: &tauri::AppHandle) -> tauri::Result<()>   // при запуске Nous
pub fn shutdown(app: &tauri::AppHandle)                     // при выходе
```

Свои части лежат рядом и подключаются через `#[path = "host.rs"] mod host;`. Команды для интерфейса — обычные `#[tauri::command]`, перечисленные в `[rust] commands`. Зависимости модуля (его собственные SDK, например `nous-veritas`) объявляются в `app/src-tauri/Cargo.toml`.

## Что даёт оболочка

| Модулю | Как |
|---|---|
| Данные игры | Nous SDK: команды `get_inventory`, `get_profile`… и события с ревизией (`@app/lib/live`) |
| Тестовый режим | `crate::launch::is_replay` — изолированная отладка без игры |
| Состояние игры | `crate::launch::LaunchState`: запущена ли игра, путь к ней |
| Включение и выключение | «Настройки → Модули»; выбор хранится в `modules.json` |

Rust-часть модуля запускается при старте Nous независимо от переключателя; выключение скрывает интерфейс модуля и останавливает его фоновую работу в интерфейсе. Модуль, чья Rust-часть что-то делает сама (как Veritas), проверяет собственные настройки.

## Как добавить модуль

1. Создать `app/modules/<id>/module.toml` и `ui.tsx` (за образец — `relics`).
2. Если нужна Rust-логика — `module.rs` с `setup`/`shutdown` и командами в `[rust] commands`.
3. `npm run test:modules` проверит манифест; `npx tsc -b`, `cargo check` — остальное.

Доставка модулей отдельно от программы (скачивание, каталог) пока не решена: все модули собираются в программу и включаются в Настройках.
