# Категории меню

Категория — раздел бокового меню с заголовком-разделителем (как COLLECTION / INVENTORY в AlecaFrame). Все категории описаны в одном файле `src/features/categories.ts`.

```ts
export const categories = [
  { id: 'main', order: 0 },
  { id: 'exploration', title: 'Исследование', order: 10 },
  { id: 'inventory', title: 'Инвентарь', order: 20 },
  { id: 'system', order: 1000, pinBottom: true },
] as const satisfies readonly CategoryDef[]
```

## Поля

| Поле | Описание |
|---|---|
| `id` | Идентификатор, на него ссылаются фичи в `category` |
| `title` | Заголовок над группой (выводится капсом с линией). Без него группа идёт без заголовка, как «Обзор» |
| `order` | Порядок разделов, меньше — выше. Берите шаг 10, чтобы было куда вставлять |
| `pinBottom` | Прижать раздел к низу меню, за разделительной линией. Так сделаны «Настройки» |

## Добавить категорию

1. Добавьте строку в `categories.ts`:
   ```ts
   { id: 'warps', title: 'Прыжки', order: 30 },
   ```
2. Укажите `category: 'warps'` в нужных фичах.

Благодаря `as const` список id становится типом `CategoryId`: если фича укажет несуществующую категорию, проект не соберётся.

## Правила

- **Пустая категория не показывается.** Можно завести её заранее.
- Внизу (`pinBottom`) только служебное: настройки, о программе, dev-экраны.
- Категория без `title` — только для самого верхнего блока (главная, обзор).
- Название категории существительным во множественном числе или названием области: «Исследование», «Инвентарь», «Прыжки».
