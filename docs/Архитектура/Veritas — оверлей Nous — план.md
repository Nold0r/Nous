# Veritas — оверлей Nous — план

Основание: подробное задание пользователя, задающее окно Tauri, дизайн Nous, официальный неизменённый плагин и проверку без игры. Источники изучены в временном target/research/veritas: commit 561f57ce06ec3943ce062473957a9b9b0747d120, 0.2.57. Реализация следует этим явно заданным границам; дополнительных продуктовых решений от пользователя не требуется.

## Подход

Выбран внешний Tauri WebView с получением Socket.IO-событий, как прямо указано в задании. Изменение DLL ради headless-режима исключено требованием официальной сборки; вывод UI самого плагина не даёт дизайн Nous и сохраняет захват игрового ввода. Готовый поток не имеет удалённых команд и не передаёт reset_action_value: эти ограничения должны быть видимы, а не имитированы.

Новый Tauri-free nous-veritas обрабатывает строгие wire-типы и агрегирует бой, историю, статистику и JSON/CSV. Tauri адаптирует Socket.IO, хранит настройки/историю отдельно от аккаунтов, управляет окном и физическими координатами клиентской области игры. UI Nous показывает активные исходные представления, дополнительно график по ходам/AV, управление колонками, экспорт, темы/масштаб/прозрачность и горячие клавиши.

Встроенный UI подавляется штатными JSON/RON-настройками: hide_ui=true, auto_showhide_ui=false, streamer_mode=false, окна закрыты, версия обновления подтверждена и beta-prompt=false. Файлы плагина читаются при запуске, поэтому запись разрешена только при закрытой игре и требует нового запуска. Абсолютно скрыть все egui-уведомления с официальной DLL нельзя; это остаётся явным ограничением.

## Ограничения проекта

- Только codex/sdk, локальные коммиты; без push/main/другого worktree.
- Не устанавливать DLL, не запускать игру и не менять её папку в ходе проверки.
- Существующие consent, github-actions[bot], SHA-256 и проверка владения DLL сохраняются.
- Dev replay доступен лишь debug + com.nous.devtest, не меняет enabled/consent и не обращается к реальной игре.
- Прозрачное окно без рамки/taskbar/focus, click-through по умолчанию; физические координаты, DPI и отрицательные координаты мониторов.
- Полноэкранный D3D определяется по сигналу Windows как возможная причина невидимости, без чтения игрового процесса; интерфейс предлагает оконный/безрамочный режим.
- Русские UI/документы, английские комментарии, существующие токены и HSR-шрифт.

## План реализации

- [ ] nous-veritas: сначала падающие тесты wire-пакетов, последовательности/перестановки начала, damage/overkill/skill/turn и финала; затем reducer, история и экспорт. Проверить malformed/unknown, late connect, disconnect и DPAV при нулевом AV.
- [ ] Платформа: тесты видимости/позиции/DPI и безопасных конфигов; окно, слежение за целевым HWND без OpenProcess, lifecycle, глобальные настраиваемые клавиши, хранение и Socket.IO. Не путать потерю фокуса с окончанием боя.
- [ ] Настройки и окно Nous: представления Legend/Character damage/Breakdown/Enemy stats/Metrics/Logs, история, JSON/CSV, масштаб, темы и параметры плагина; не выдумывать скрытые wire-данные.
- [ ] Socket.IO simulator на 127.0.0.1:1305 со схемой 0.2.57 и управляемыми сценариями/ошибками, отдельное тестовое окно-цель. Проверить begin/end/disconnect/закрытие цели/смену настроек/сохранённый итог.
- [ ] Полный workspace, lint, tsc, build, module tests, native debug/CDP и снимки. Обновить заметку, Unreleased и отчёт с матрицей переноса и ограничениями.

## Проверки риска

Конфиг RON нельзя частично записать без обязательных полей; сохранять неизвестные параметры и оригинал. Пакеты бывают в другом порядке; не смешивать два боя. Поздний клиент не восстанавливает потерянные hit/skill/stat данные и должен помечать неполноту. Не перезаписывать итог целым нулевым stage_id из известного дефекта upstream. Ошибка соединения и закрытие игры скрывают окно; история не пропадает. Экспорт и автоматические пути проверять на временных папках. Бета-обновления не должны обходить bot/hash-проверки; Nous не выполняет команд изменения Defender.
