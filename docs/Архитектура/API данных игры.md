# API данных игры

Всё, что Nous знает об аккаунте, доступно через независимый Rust [[SDK]], а фронту — через прежние команды и события Tauri. Данные лежат в файле аккаунта ([[Данные аккаунта]]) и обновляются вживую, пока работает [[Сниффер]].

## Безопасность: почему это не трогает античит

| Способ | Что делает | Почему безопасно |
|---|---|---|
| Копия трафика (PktMon) | Windows отдаёт Nous **копию** сетевых пакетов игры, reliquary расшифровывает | Процесс игры не открывается, память не читается, код не внедряется, пакеты не отправляются и не меняются. Античит (HoYoKProtect) защищает процесс и его память — туда Nous не заходит. Так же работает reliquary-archiver, которым годами пользуются вместе с оптимизатором Fribbels |
| Веб-кеш игры на диске | Nous читает файл `webCaches/…/data_2`, который игра пишет сама | Обычное чтение файла, игра не замечает |
| Официальный API истории прыжков | Тот же запрос, что делает страница истории в игре, с паузой 0,4 с между страницами | Так работают все трекеры прыжков (StarRailStation, Paimon.moe и т. п.); нагрузка как у человека, листающего историю |

> [!warning] Чего Nous не делает и делать не должен
> Чтение или запись памяти игры, инъекции DLL, перехват отрисовки, отправка своих пакетов, автоматизация игровых действий в релизной программе. Dev-скрипт [[Вход в игру скриптом]] эмулирует клики и **не входит в приложение**.

Исключение — опция [[Veritas — урон в реальном времени]]: она **внедряется в игру**, выключена по умолчанию и включается только с явным согласием пользователя на риск.

Ограничение пассивного способа: видно только то, что игра передаёт по сети. Бой считается в клиенте, поэтому **урона по ударам вживую нет** — только итоговый отчёт, который клиент отправляет серверу в конце боя (он подробный, см. ниже).

## Ревизии и смена аккаунта

Каждое изменение состояния увеличивает **ревизию**. Все команды чтения отдают `{ revision, data }`, все события — тоже. Хуки строятся на `useLive` (`lib/live.ts`): сначала подписка, потом чтение; события, пришедшие во время чтения, применяются, только если они новее; старые события отбрасываются.

Когда входит другой аккаунт, приходит событие **`account-changed`** (`data` — новый UID): всё, что держал потребитель, недействительно, `useLive` перечитывает данные сам. Своим хукам вне `useLive` нужно делать так же.

## Разделы

| Раздел | Команда | Событие | Хук (`src/lib/`) | Источник |
|---|---|---|---|---|
| Профиль | `get_profile` | `profile-changed` | `useProfile` | вход, синхронизация |
| Инвентарь: реликвии, конусы, материалы, персонажи | `get_inventory`, `get_relics` | `inventory-changed` | `useInventory` | вход, синхронизация, см. [[Данные аккаунта]] |
| Мир: локация, позиция, сундуки, объекты | `get_world` | `world-changed` (только изменившиеся этажи), `player-moved` | `useWorld` | вход в сцену, движение, карта в игре, открытие сундуков |
| Бои | `get_battles` | `battle-finished` | `useBattles` | `PVEBattleResultCsReq` в конце каждого боя |
| Прыжки | `get_gacha`, `import_gacha_history` | `gacha-changed` | `useGacha`, `importGachaHistory` | баннеры при входе, крутки вживую, история из официального API |
| Снимки (всё остальное) | `get_snapshots`, `get_snapshot(name)`, `get_snapshot_kinds` | `snapshot-changed` | `useSnapshot(name)` | последние ответы игры, см. ниже |

Код моделей: `crates/nous-core/src/`; protobuf-адаптер: `crates/nous-hsr/src/`; IPC: `app/src-tauri/src/ipc.rs` — `world.rs`, `battles.rs`, `gacha.rs`, `snapshots.rs`, `inventory.rs`, `account.rs`; фронт — `lib/game-data.ts`, `lib/inventory.ts`.

### Бои

В конце боя клиент отправляет статистику (`BattleStatistics`). На каждого персонажа:

- урон всего, урон по уязвимости (break), лечение, щиты, полученный урон;
- урон по типам атак (`Normal`, `BPSkill`, `Ultra`, `Insert` — доп. атаки, `DOT`…) и **самый сильный удар** каждого типа;
- использование навыков, ходы, пробития, смерти, потраченные/набранные очки навыков;
- надетые реликвии (их `uid`) и конус; для персонажа поддержки — UID владельца.

- **значение действия** (`actionValue`) и **DPAV** — урон на единицу значения действия всего боя, метрика из Veritas.

На бой: этап (`stageId`), результат, время, ходы, ульты, циклы, счёт испытания; по врагам — урон и полученный урон. Ещё на бой — **журнал действий** (`actions`, из `op_list`): номер хода, кто, по кому, какой навык. Id существ локальны для боя; соответствие персонажам ещё нужно сверить на настоящих боях. Хранятся последние 200 боёв.

> [!note] Почему не как Veritas
> [Veritas](https://github.com/hessiser/veritas) показывает урон каждого удара вживую, но это DLL **внутри процесса игры**: перехват функций движка (`detour`), чтение структур IL2CPP в памяти, оверлей DirectX 11. Это ровно то, что ловит античит. Nous берёт у него только модель данных и метрики (DPAV, журнал ходов), а сами данные — из отчёта о бое в трафике.

### Прыжки

1. Откройте в игре **Прыжки → История** (любой баннер). Игра запишет ссылку с ключом в веб-кеш; ключ живёт ~сутки.
2. `importGachaHistory()` скачивает историю всех баннеров (стандартный, новичка, персонажи, конусы, коллаборации), останавливаясь на уже известных записях, — повторный импорт быстрый.

Проверено 02.11.2026: 1071 прыжок, 56 с.

### Снимки

Последний ответ игры целиком (JSON полей протокола; часть имён обфусцирована). Список — `get_snapshot_kinds`:

| Команда | Что внутри |
|---|---|
| `GetDailyActiveInfoScRsp` | ежедневная тренировка |
| `GetExpeditionDataScRsp`, `ExpeditionDataChangeScNotify` | поручения |
| `GetChallengeScRsp`, `GetChallengePeakDataScRsp` | Зал забвения, Чистый вымысел, Иллюзия конца, пиковые испытания |
| `GetAllLineupDataScRsp`, `GetCurLineupDataScRsp` | отряды |
| `BattlePassInfoNotify` | Безымянная слава |
| `GetRogueInfoScRsp`, `RogueTournQueryScRsp` | Виртуальная и Расходящаяся вселенные |
| `GetMissionDataScRsp`, `GetQuestDataScRsp` | задания, достижения |
| `GetMailScRsp`, `GetFriendListInfoScRsp` | почта, друзья |
| `GetMarkChestScRsp` | отмеченные сундуки |
| `GetBattleCollegeDataScRsp`, `GetTrainVisitorRegisterScRsp` | Обучение боям, гости Экспресса |

Когда фича начнёт пользоваться снимком всерьёз, его стоит превратить в типизированный раздел, как бои или инвентарь.

## Проверки

- `cargo test --lib` — разбор боёв, кеша и импорта прыжков, инвентаря, записи входа.
- `npm run test:data` — прогон записанных входов: инвентарь, мир, баннеры, снимки ([[Данные аккаунта#Проверки без входа в игру]]).
- `NOUS_GAME_EXE=… NOUS_UID=… cargo test --lib live_history -- --ignored --nocapture` — настоящий импорт прыжков с ключом из кеша этого ПК.
