# Veritas — урон в реальном времени

> [!danger] Единственное место, где Nous внедряется в игру
> Всё остальное в Nous пассивно ([[API данных игры#Безопасность: почему это не трогает античит]]). Veritas — **DLL внутри процесса игры**: перехват функций движка и чтение памяти. Это нарушает Пользовательское соглашение HoYoverse; античит может это обнаружить, вплоть до блокировки аккаунта. Поэтому опция **выключена по умолчанию**, включается только в настройках после явного согласия, и ответственность несёт пользователь.

[Veritas](https://github.com/hessiser/veritas) (MIT) — оверлей-дамаг-логгер для HSR. Сам автор пишет: «не соответствует Пользовательскому соглашению… мы не можем гарантировать защиту от санкций».

## Как это устроено в Nous

Код: `src-tauri/src/veritas.rs`, фронт: `lib/veritas.ts`, `features/settings/VeritasSettings.tsx`.

| Шаг | Что делает Nous |
|---|---|
| По умолчанию | Ничего. В папке игры нет файлов Veritas, подключения нет |
| Включение (Настройки → «Встроить Veritas в игру») | Показывает предупреждение; кнопка активна только после флажка «Я понимаю риски…». Игра должна быть закрыта |
| Установка | Последний релиз с GitHub API; проверки: релиз и файл собраны `github-actions[bot]` (как советует автор), SHA-256 совпадает с `digest` релиза. Файл кладётся рядом с `StarRail.exe` как `xluau.dll` (способ 2 из вики Veritas: игра сама грузит этот файл). Чужой файл с таким именем не трогается |
| Пока включено | Когда игра запущена, Nous подключается клиентом к Socket.IO-серверу Veritas `127.0.0.1:1305` и пересылает каждый пакет событием `veritas` |
| Выключение | Удаляет `xluau.dll` (только если это файл Nous: сверка SHA-256). Игра должна быть закрыта |

Состояние: `%APPDATA%\com.nous.companion\veritas.json` (включено ли, когда принят риск, версия, хэш, поддерживаемые версии игры).

**Совместимость.** В описании релиза есть `Game Version: 4.3.54 - 4.6.52`; Nous сравнивает с `game_version` из `config.ini` игры и предупреждает в настройках, если версия вне диапазона (плагин может ронять игру — тогда выключить).

## API

| Команда / событие | Что |
|---|---|
| `get_veritas_status` | `{ enabled, version, gameRange, gameVersion, compatible, connected }` |
| `enable_veritas(acceptRisk)` | установка; без `acceptRisk: true` — отказ |
| `disable_veritas` | удаление |
| событие `veritas-status` | состояние изменилось (подключение, установка) |
| событие `veritas` | `{ name, data }` — пакет Veritas |
| хуки | `useVeritasStatus()`, `useVeritasPackets(cb)` |

Пакеты Veritas (`docs/API.md` в его репозитории): `OnBattleBegin`, `OnSetBattleLineup`, `OnDamage` (атакующий, урон, перебор урона, тип), `OnTurnBegin` (значение действия), `OnTurnEnd`, `OnUseSkill`, `OnEntityDefeated`, `OnUpdateWave`, `OnUpdateCycle`, `OnStatChange`, `OnUpdateTeamFormation`, `OnInitializeEnemy`, `OnBattleEnd` (итоги, история ходов и значения действия).
