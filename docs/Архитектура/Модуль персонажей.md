# Модуль персонажей

Модуль `characters` (`app/modules/characters/`, см. [[Модули]]). Две страницы:

| Адрес | Что |
|---|---|
| `/#/characters` | Сетка персонажей (`PortraitCard`): бюст, стихия и путь, эйдолоны, уровень, надетый конус с наложением, отметка заметки. Поиск по имени и заметкам, сортировка (уровень, редкость, эйдолоны, имя), фильтры с белым и чёрным списком (`FilterMenu`): стихия, путь, редкость, состояние (с заметкой, без конуса, не все реликвии) |
| `/#/characters/<id>` | Персонаж: портрет, уровень, эйдолоны (наведение — описание), заметка; итоговые характеристики; умения с уровнями (+ от эйдолонов); бонусы следов; конус; шесть реликвий и активные бонусы наборов |

`<id>` — id пути (`avatarPaths`): у Первопроходца и Мартовской 7 у каждого пути своя сборка и своя заметка.

## Данные

- Сборка — `useInventory()`: `avatars` (уровень и возвышение, общие для путей), `avatarPaths` (эйдолоны, следы, конус, реликвии по слотам), см. [[Данные аккаунта]].
- Таблицы — `game-data-characters.json` (`npm run game-data`, грузится только этим модулем, `useCharacterTables()`): базовые характеристики по возвышениям, характеристики и пассивки конусов, следы, умения, эйдолоны, стихии, пути.
- Картинки — StarRailRes: `icon/character/<id>.png` (бюст), `image/character_portrait/<id>.png` (полный арт).
- Логика — `src/lib/characters.ts` (`viewCharacter`, `shownPaths`, `formatTotal`).

### Пути и Первопроходец

- Уровень пути берётся из `avatars`: по id пути, по `currentPath`, для Мартовской 7 (1224 → 1001) и Первопроходца (любой 8xxx) — по базовому персонажу.
- Игра хранит пути Первопроходца обоих полов (нечётные — один пол, чётные — другой). Показываются только пути того же пола, что и выбранный сейчас (`currentPath`). Не выбранные в игре пути приглушены.
- Имя Первопроходца — ник из профиля.

### Следы

В `skillTree` ключ — номер точки (`"1"` = `Point01`), не полный id. Сопоставляется с таблицей по `anchor`. Точки с умением (`Point01`–`04`, умения спутника) показываются в «Умениях»; малые следы с характеристиками — в «Бонусах следов» и в итоге. Уровень умения от эйдолонов: сумма `level_up_skills` открытых эйдолонов для умения этой точки.

## Итоговые характеристики

Как на экране персонажа в игре, без условных бонусов (то, что включается в бою):

- база персонажа = `base + step × (уровень − 1)` по возвышению; база конуса так же;
- **HP, ATK, DEF** = (база персонажа + база конуса) × (1 + Σ%) + Σ плоских;
- **SPD** = база персонажа × (1 + Σ%) + Σ плоской;
- крит. шанс 5% и крит. урон 50% из таблицы + бонусы; остальное — сумма бонусов, восстановление энергии от 100%;
- бонусы: основные и доп. характеристики реликвий, безусловные бонусы наборов (2/4 предмета), малые следы, безусловная пассивка конуса по наложению;
- бонус урона — своей стихии; «Радость» показывается, только если она есть.

Округление как в игре: целые вниз (скорость тоже), проценты — один знак. Подсказка у HP/ATK/DEF/SPD: точное значение = база + бонус (скорость с десятыми).

> [!success] Проверено в игре (05.11.2026, 4.6)
> Эванесса (E6, 4+2 набора, следы, конус): HP 2902, ATK 2465, DEF 1104, SPD 109, крит 61,9% / 273,0% — совпадает с экраном персонажа в игре до единицы.

## Заметки

Как у реликвий (см. [[Модуль инвентаря#Заметки к реликвиям]]): `notes.characters` в файле аккаунта, ключ — id пути. `Client::set_character_note`, команда `set_character_note(avatarId, text)`, событие `notes-changed`.

## Проверка

- `cargo test -p nous-core` — заметки персонажей отдельно от заметок реликвий, сохранение и событие.
- Вживую: `npm run tauri dev`, вход в игру скриптом ([[Вход в игру скриптом]]), «Персонажи». Сверка с игрой: в игре клавиша C — экран персонажа.
