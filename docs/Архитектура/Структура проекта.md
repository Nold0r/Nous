# Структура проекта

```text
Cargo.toml                    Cargo workspace и профили сборки
Cargo.lock                    единые зафиксированные Rust-зависимости
crates/
  nous-core/src/
    account.rs                Account, AccountStore, FileStore, миграция
    game.rs                   Command, GameState, Versioned
    sdk.rs, events.rs         Client, saver, подписки, события
    profile.rs, inventory.rs  предметные модели и слияние данных
    world.rs, battles.rs      мир и бои без protobuf
    gacha.rs, snapshots.rs    прыжки и снимки
  nous-core/tests/            публичный API и ошибки хранилища
  nous-hsr/src/
    lib.rs, sniffer.rs         Sdk, захват и его запуск/остановка
    decode.rs                 protobuf → Command
    inventory.rs, world.rs    преобразование пакетов
    battles.rs, snapshots.rs  преобразование пакетов
    gacha.rs                  преобразование пакетов, официальный импорт
    recorder.rs, replay.rs    запись и воспроизведение входа
    mapscan.rs                сверка меток карты с игрой
  nous-hsr/tests/             публичный lifecycle SDK
  nous-veritas/src/           SDK модуля Veritas: события боя, модели, экспорт
examples/events.rs            консольный потребитель без Tauri
app/
  src-tauri/src/
    lib.rs, ipc.rs            тонкая интеграция SDK с Tauri
    module_config.rs          атомарные настройки платформы, отдельно от аккаунтов
    launch.rs                 окно, трей, запуск и автозапуск
    sniffer.rs                перезапуск от администратора
  src-tauri/build.rs          находит модули и их команды в app/modules/
  modules/<id>/               модули: всё, кроме аккаунта и Настроек (см. Модули.md)
    module.toml               как показать модуль в программе
    ui.tsx                    лёгкая точка входа: ленивый экран, иконка, start, overlay
    page.tsx                  сам экран, отдельный чанк, грузится при первом открытии
    module.rs                 Rust-часть, если она нужна (сейчас только у veritas)
  src/
    App.tsx                   оболочка и маршруты активных экранов
    features/
      types.ts                ModuleDef, ScreenDef, сервисы и контекст
      registry.ts             встроенные модули и группировка экранов
      ModuleProvider.tsx      сохранённый выбор и подключение сервисов
      module-runtime.ts       независимый от маршрутов lifecycle
      module-context.ts       React-контекст платформы
      manifest.ts             module.toml + экспорты ui.tsx → ModuleDef
      settings/               обязательный экран оболочки
    components/, lib/, ui/    каркас, общая логика, дизайн-система
    lib/live-core.ts          синхронизация состояния с Rust без React (тестируется в node)
  scripts/tests/              node-тесты: модули, манифесты, live, округление характеристик
vendor/reliquary/              закреплённый git submodule
spike/                        отдельные исследовательские проекты, вне workspace
audit/2026-11-03/             аудит Codex (S01–S28) с воспроизведениями, вне workspace
docs/                         русская документация Obsidian
```

Результаты Cargo лежат в корневом `target/`, а не в `app/src-tauri/target/`. На машине разработки `target` — junction на быстрый диск, см. [[Запуск и сборка]]. Tauri CLI находит workspace автоматически. Сборка, тесты и пример описаны в [[SDK]] и [[Запуск и сборка]].
