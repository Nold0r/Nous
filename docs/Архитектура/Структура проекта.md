# Структура проекта

```
Nous/
├─ app/                          приложение
│  ├─ src/
│  │  ├─ main.tsx                точка входа, подключает стили
│  │  ├─ App.tsx                 фон + меню + маршруты фич
│  │  ├─ shell.css               стили оболочки (меню, профиль)
│  │  ├─ ui/                     ДИЗАЙН-СИСТЕМА
│  │  │  ├─ tokens.css           токены: цвета, отступы, шрифт…
│  │  │  ├─ base.css             сброс стилей, .acrylic, утилиты
│  │  │  ├─ components.css       стили компонентов
│  │  │  ├─ index.ts             публичный API: import { … } from '../../ui'
│  │  │  └─ *.tsx                Page, Panel, Button, Tabs, StatRow…
│  │  ├─ components/             части оболочки
│  │  │  ├─ background/          анимированный космос (SpaceBackground)
│  │  │  └─ sidebar/             Sidebar, ProfileCard
│  │  ├─ features/               ЭКРАНЫ
│  │  │  ├─ types.ts             FeatureDef, CategoryDef, defineFeature
│  │  │  ├─ categories.ts        разделы меню
│  │  │  ├─ registry.ts          автосбор фич
│  │  │  └─ <id>/index.ts        описание экрана + его компоненты
│  │  ├─ lib/                    общая логика (profile, format, icons)
│  │  └─ assets/                 иконки и шрифт (генерирует npm run assets)
│  ├─ scripts/
│  │  ├─ assets.json             какие иконки и шрифты качать
│  │  └─ fetch-assets.mjs        загрузка и нормализация ресурсов
│  └─ src-tauri/                 Rust
│     ├─ src/lib.rs              регистрация команд
│     ├─ src/profile.rs          профиль игрока
│     └─ tauri.conf.json         окно, сборка
├─ docs/                         эта документация (Obsidian)
├─ spike/                        черновые эксперименты (сниффер, датамайн)
└─ vendor/                       чужие репозитории для справки (reliquary…)
```

> [!note] spike и vendor
> `spike/hsr-sniff` — рабочий прототип сниффера, на нём проверены пакеты карты и сундуков, см. [[Протокол — карта и сундуки]]. В приложение он пока не встроен.
